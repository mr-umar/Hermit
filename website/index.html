How Hermit works

Zero pre-baked clutter. An intelligent onboarding that adapts to whether you have an NFC tag.

1

1. Pair your NFC tag (skippable)

Tap any standard NTAG213, NTAG215, or NTAG216 tag to pair it. Don't have one yet? Tap "Skip for now" to continue.

2

2. Adaptive profile creation

Hermit tailors options to your setup: timer-based locking if you have no tag, or universal NFC switch + Zen Mode if you have a tag.

3

3. Engage your focus

Tap your physical desk tag or start the timer. Hermit enforces focus for up to 12 hours with unyielding consistency.

4

4. Mindful barrier & Zen launcher

Distracting apps are met with a calm reflection screen or secluded within the Zen Launcher. Exit only when intention is renewed.

Intelligent adaptive setup

No default profiles forced upon you. Hermit unlocks tailored capabilities depending on your physical setup.

Without NFC Tag (Timer Mode)

Timer-based focus sessions

If you haven't added an NFC tag yet, you can create focused profiles guarded by a strict countdown timer.

  • Configurable timer up to a maximum of 12 hours
  • Emergency exit enabled by default with a 60-second reflection pause
  • Optional: Disable emergency exit completely for an unbypassable lock
  • Zen Launcher mode disabled (requires physical NFC to exit safely)
With NFC Tag (Physical Switch)

Physical friction & Zen Launcher

Pairing an NFC tag anchors your commitment in the real world and unlocks the full power of Hermit.

  • Universal physical switch: Tap to toggle active focus on/off
  • Unlock Zen Mode: replaces home screen with OLED essentials
  • Deactivate exclusively with physical NFC tag
  • Internal 12-hour ceiling guarantees safety under all conditions

Anti-tamper & uninstall protection

During moments of weakness, the impulse to delete your focus app can be overwhelming. Hermit integrates Android Device Administrator protection to disable the system uninstall button. Disabling protection requires waiting out a mindful reflection timer, giving your rational self time to take over.

Hardware compatibility

Hermit avoids vendor lock-in. Use affordable, standard NFC tags rather than proprietary accessories.

Chip / standard Usable capacity Compatibility Notes
NTAG213 144 bytes Fully supported 144 bytes user memory. Perfect for Hermit's compact payload (<120 bytes). Highly affordable.
NTAG215 504 bytes Fully supported 504 bytes user memory. Widely available and fully tested with read-back verification.
NTAG216 888 bytes Fully supported 888 bytes user memory. Maximum capacity for Type 2 tags.
ISO 14443-4 / Type 4 Variable Conditional Standard NDEF tags supported subject to phone NFC controller compatibility.

Installation & source code

Hermit is free, open source, and built entirely with native Kotlin & Jetpack Compose.

Build from source

Clone the repository from GitHub:

git clone https://github.com/mr-umar/Hermit.git
cd Hermit

Build debug APK with Gradle:

./gradlew assembleDebug

Install directly via ADB to your device:

adb install -r app/build/outputs/apk/debug/app-debug.apk
