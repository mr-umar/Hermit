How Hermit works

Transform an inexpensive NFC tag into a physical sanctuary from digital distractions.

1

1. Configure your profile

Choose which distracting social, video, or communication apps to silence and set optional session durations.

2

2. Write the physical tag

Hold any standard NTAG213, NTAG215, or NTAG216 tag to your phone. Hermit writes a verified NDEF message with an Android Application Record.

3

3. Tap to engage

Tap the tag on your desk or doorway. Hermit instantly activates your focus mode, even if the app is closed or running in the background.

4

4. Genuine app & web blocking

Opening blocked apps or visiting social media in browsers triggers a mindful breathing pause, requiring your physical tag to exit.

Built for intention, not addiction

Everything you need to protect your deep work sessions without proprietary pucks or recurring subscriptions.

Universal NFC compatibility

Works with standard, inexpensive NFC Forum Type 2 tags (NTAG213, NTAG215, NTAG216) readily available anywhere online.

Real accessibility blocking

A genuine Android AccessibilityService intercepts distracting foreground app launches and browser URLs cleanly without root.

100% local-first & private

Zero accounts, zero trackers, zero cloud dependencies. Internet access is strictly used to check and download updates from GitHub Releases; your focus habits and data stay entirely on your phone.

Flexible & secure exit behaviors

Choose between physical NFC tag unlocking (maximum 24 hours for safety), auto-timer release, or emergency reflection countdowns.

Monk sanctuary & custom profiles

Includes the Monk mode profile (whitelisting only Phone, Camera, WhatsApp, Spotify, and Maps) alongside fully customizable modes.

Local session metrics & history

Track your total focus hours, completed sessions, and prevented distraction attempts securely in encrypted local Room storage.

Hardware compatibility

Hermit avoids vendor lock-in. Use affordable, standard NFC tags rather than proprietary accessories.

Chip / standard Usable capacity Compatibility Notes
NTAG213 144 bytes Fully supported 144 bytes user memory. Perfect for Hermit's compact payload (<120 bytes). Highly affordable.
NTAG215 504 bytes Fully supported 504 bytes user memory. Widely available and fully tested with read-back verification.
NTAG216 888 bytes Fully supported 888 bytes user memory. Maximum capacity for Type 2 tags.
ISO 14443-4 / Type 4 Variable Conditional Standard NDEF tags supported subject to phone NFC controller compatibility.

A transparent digital wellbeing shield

Hermit contains no Google Analytics, no Firebase, no crash trackers, and no ad SDKs. Network access is strictly used to check GitHub Releases for app updates.

Installation & source code

Hermit is free, open source, and built entirely with native Kotlin & Jetpack Compose.

Build from source

Clone the repository from GitHub:

git clone https://github.com/mr-umar/Hermit.git
cd Hermit

Build debug APK with Gradle:

./gradlew assembleDebug

Install directly via ADB to your device:

adb install -r app/build/outputs/apk/debug/app-debug.apk
